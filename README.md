# Laleo

A daily Christian confession app. Read your confession aloud and the words follow your voice, line by line, like a teleprompter. Finish each day to build a streak.

## Features

- **Voice follow-along**: speech recognition matches what you say to each line and moves on when you finish it. A live waveform shows your real mic input.
- **Fallback**: if speech or the mic isn't available, tap the text to move line by line.
- **Daily streak**: completing a confession records the day and shows your week's progress. Saved in the browser for now.
- **Web showcase**: on desktop the app sits in a phone frame; on phones it runs full screen.


## Stack

React 18, Vite 5 and plain CSS. No backend yet.
